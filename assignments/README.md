# Assignments

This folder contains the problem sets for [DATASCI 185: Introduction to AI Applications](https://danilofreire.github.io/datasci185/)

## How to Download the Assignment Files

Each assignment is available in **three formats**, just use whichever you prefer:

| Format | File Extension | Best For |
|--------|----------------|----------|
| **Jupyter Notebook** | `.ipynb` | If you want to write answers directly in cells |
| **Quarto** | `.qmd` | If you use RStudio or Quarto |
| **Word** | `.docx` | If you prefer working in Microsoft Word |

### Download Instructions

1. **Navigate to the file** you want to download (e.g., `01-assignment.ipynb`)
2. **Click on the file name** to open it
3. Look for the **"Download raw file"** button (download icon ⬇️) in the top-right corner of the file preview
4. Click to download the file to your computer

You can also **download the entire repository**:

1. Go to the main page of the course repository: <https://github.com/danilofreire/datasci185>
2. Click the green **"Code"** button
3. Select **"Download ZIP"**
4. Extract the ZIP file and find the assignments in the `assignments/` folder

## Submission Guidelines

- **Submit via Canvas** by the deadline indicated on the syllabus
- Submit as a **PDF** (preferred), as a Word document (`.docx`) or as a Jupyter Notebook (`.ipynb`)
- **AI use is encouraged**: You may use ChatGPT, Claude, Gemini, or other LLMs to help explore questions
- **All responses must be written in your own words** and demonstrate understanding
- For each assignment, briefly **mention which AI tool you used** (if any)
- **Screenshots of your AI interactions** are encouraged where relevant
- Each answer should be at least **150-200 words** (be concise but thorough)

## Academic Integrity

While AI tools are allowed and encouraged for exploration and learning, you must:

1. Write all final answers in your own words
2. Demonstrate critical thinking, not just copy-paste LLM outputs
3. Disclose which AI tools you used
4. Take responsibility for the accuracy of your submissions

Please refer to the course syllabus for the full academic integrity policy.
